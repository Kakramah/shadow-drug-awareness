# الظل — حملة توعية لمكافحة المخدرات

موقع عربي توعوي يعرض مشاهد بصرية ومعلومات وإرشادات حول المخدرات وآثارها.

**الموقع:** https://kakramah.github.io/shadow-drug-awareness/

## البنية

- `index.html`: المحتوى والمشاهد والروابط.
- `css/main.css`: ملف التصميم الذي تحمّله الصفحة.
- `scss/main.scss`: مصدر SCSS موجود في المستودع؛ إذا عُدّل، راجع توافقه مع CSS المنشور.
- `js/`: التفاعلات والتنقل.
- `images/` و`fonts/`: الصور والخطوط المحلية.

## المعاينة

من جذر المستودع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000/` وراجع المشاهد والتنقل وروابط الإرشاد على الهاتف والحاسوب قبل الدمج. لا يظهر إعداد بناء في جذر المستودع؛ الصفحة تستخدم `css/main.css` مباشرة.
